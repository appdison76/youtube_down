⚠️ 설치 권한 설정 안내

APK 설치를 위해서는 먼저 설치 권한을 허용해야 합니다. 폰 제조사와 안드로이드 버전에 따라 설정 경로가 다를 수 있습니다.

📱 방법 1: 자동 설정 (권장)
  • APK 파일을 다운로드 후 열어보세요
  • "이 앱을 설치할 수 없음" 메시지가 나타나면
  • 메시지의 "설정" 또는 "권한 허용" 버튼을 클릭하세요
  • 해당 앱(Chrome 또는 파일 관리자)에 대해 "이 앱 설치 허용"을 켜주세요
⚙️ 방법 2: 수동 설정
  • 최신 안드로이드 (14+): 설정 → 보안 및 개인정보 보호 → 보안 위험 자동 차단 해제
  • 안드로이드 8.0~13: 설정 → 앱 → Chrome(또는 사용한 브라우저) → 이 앱 설치 허용
  • 삼성 갤럭시: 설정 → 바이오메트릭 및 보안 → 알 수 없는 앱 설치 → Chrome 선택 → 허용
  • 구글 픽셀: 설정 → 보안 → 알 수 없는 앱 설치 → Chrome 선택 → 허용
  • 샤오미: 설정 → 앱 → 권한 → 알 수 없는 소스 설치 → Chrome 허용
  • LG: 설정 → 보안 → 알 수 없는 소스 설치 허용

💡 팁: 파일이 크므로 WiFi 환경에서 다운로드하세요. 다운로드가 완전히 끝날 때까지 기다려주세요.
